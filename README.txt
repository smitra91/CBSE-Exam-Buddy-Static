CBSE EXAM BUDDY — STATIC GITHUB PAGES VERSION

Files required:
  index.html
  styles.css
  app.js
  pdf-loader.js
  pdf.min.mjs
  pdf.worker.min.mjs

No API key, package installation, build process, or GitHub Actions workflow is required.

PDF support works locally in the browser for PDFs containing selectable text. Scanned/image-only PDFs require OCR and are not supported.

The chapter picker supports selecting multiple predefined chapters and adding custom chapter names.

Question generation separates extracted PDF text by the checked chapter names and creates varied MCQ, fill-in-the-blank, true/false, definition, short-answer, explanation and long-answer questions from matching PDF sentences.

Publish from GitHub repository Settings > Pages > Deploy from a branch > main > /(root).
